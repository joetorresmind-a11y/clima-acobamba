    PUESTA EN MARCHA

    Termina la conexión con Firebase

    La aplicación usa tu proyecto Firebase. Para activar las cuentas y guardar observaciones en la nube, verifica lo siguiente en Firebase Console:

    1. Activa Authentication → Correo electrónico/contraseña.
    2. Crea la base de datos Cloud Firestore.
    3. Publica el archivo firestore.rules incluido en el proyecto.
    4. Confirma que el dominio de la página figure como dominio autorizado.

    El rol administrador se asigna manualmente al documento users/{uid}. Las cuentas nuevas se crean como observadoras.
